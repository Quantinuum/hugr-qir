# Result Recording

This page collects caveats for recording and retrieving results when submitting QIR generated by `hugr-qir` to H-Series systems.

## Supported Result Types

`hugr-qir` currently supports recording integer and boolean results through Guppy's `output` function.

## Boolean Results

Boolean result retrieval on the Nexus platform has interpretation caveats. In particular, boolean results may be represented as the last bit of a 64-bit bitstring.

For easier result interpretation, consider packing one or more boolean results into an integer before recording them.
